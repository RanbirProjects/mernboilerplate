echo MERN Blog App

A blog application built with MongoDB, Express.js, React, and Node.js, customized from mernboilerplate by Ranbir Singh.

 Folder Structure
- `server/`: Node.js/Express API with MongoDB.
- `client/`: React frontend with Tailwind CSS.
- `.gitignore`: Excludes `node_modules`, `.env`, system files.

Setup Instructions
Backend
1. Navigate to `server`: \`cd server\`
2. Install dependencies: \`yarn install\`
3. Create \`.env\` with \`MONGO_URI\`, \`JWT_SECRET\`, \`PORT\`.
4. Start MongoDB locally.
5. Run: \`yarn dev\`

Frontend
1. Navigate to `client`: \`cd client\`
2. Install dependencies: \`yarn install\`
3. Run: \`yarn start\`

Troubleshooting**: If \`localhost:3000\` is blank, check console errors and verify \`client/src/App.js\`.

 Features
- JWT-based authentication.
- Blog post CRUD operations.
- Responsive UI with Tailwind CSS.

GitHub Upload
